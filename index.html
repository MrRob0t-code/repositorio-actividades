Cuatro ideas que guían el diseño

Una página inclusiva cumple los principios de las pautas WCAG del W3C. Así se aplican aquí:

Perceptible
Contraste alto, texto ajustable, descripciones en imágenes y subtítulos en videos.
Operable
Todo funciona con teclado, con foco visible y botones grandes.
Comprensible
Lenguaje claro, títulos ordenados y navegación igual en toda la página.
Robusto
HTML semántico que funciona con lectores de pantalla y en cualquier dispositivo.

Ruta de trabajo

Así se construyó este sitio durante la unidad. Es un proceso en orden, de la investigación a la publicación.

  1. InvestigarBusqué videos y sitios sobre diseño web inclusivo y registré lo aprendido en la tabla de evidencia.
  2. DiseñarDefiní la estructura, la paleta de colores con buen contraste y las tipografías de lectura fácil.
  3. ConstruirProgramé el sitio con HTML semántico, CSS y un panel de ajustes de accesibilidad.
  4. Revisar y publicarProbé con teclado, WAVE y el verificador de contraste, y lo publiqué como repositorio de actividades.

Cómo se hizo accesible este sitio

  • Panel de accesibilidad: el botón fijo abajo a la derecha cambia el tamaño del texto, el tema (claro, oscuro o alto contraste), el espaciado y la tipografía de lectura fácil. Tus ajustes se guardan.
  • Lectura en voz alta: el mismo panel puede leer la página completa.
  • Teclado: usa Tab para avanzar, Enter para activar y Esc para cerrar el panel.
  • Tipografías: Atkinson Hyperlegible, creada para personas con baja visión, y Lexend, pensada para mejorar la fluidez al leer.
  • Multimedia: todo video lleva subtítulos y transcripción; toda imagen, texto alternativo.

Declaración de accesibilidad

Este sitio busca cumplir el nivel AA de las pautas WCAG 2.2. Se revisó con WAVE, el verificador de contraste de WebAIM y navegación solo con teclado.
